# 📏 Chaspak Savdo

Chaspakni metrlab sotish uchun oddiy telefon ilovasi (PWA). Internetsiz ishlaydi, ma'lumotlar telefonning o'zida saqlanadi.

## Imkoniyatlar
- **Kirim** — sotib olingan chaspak: nomi, metri va to'langan summa. 1 metr tannarxi avtomatik hisoblanadi.
- **Sotuv** — necha metr va 1 metr narxi kiritiladi: mijoz to'laydigan summa, foyda va qoldiq darhol ko'rinadi. Sotilgan metr ombordan ayriladi.
- **Harajat** — ijara, yo'l kira va boshqa harajatlar.
- **Asosiy** — bugun / 7 kun / shu oy / hammasi bo'yicha: tushum, tannarx, yalpi foyda, harajat va sof foyda. Har bir chaspak turi bo'yicha qoldiq.
- **Zaxira** — ma'lumotlarni JSON faylga saqlash va tiklash.

## Ishga tushirish
GitHub Pages yoqilgan bo'lsa, havolani telefonda oching va brauzer menyusidan **"Bosh ekranga qo'shish"** ni bosing — ilova kabi ochiladi.
